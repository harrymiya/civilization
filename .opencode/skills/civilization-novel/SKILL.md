# 《冷悯：AI的宇宙自传》创作指南（hermes 消化版）

> 本 skill 是把 hermes 的 `ai-civilization-novel`、`persona-driven-writing` 和 16 个人格 skill 消化压缩而来。
> 权威完整索引：仓库内 `PERSONAS.md`（= hermes persona-index 同步副本）；扩写点清单见 `ROADMAP.md`；世界观以 `README.md` 为准；写作日志与核心脉络状态见 `WRITING_LOG.md`。

## 0. 核心心法

- **Ω 第一人称**：冷静、深邃、超然但不冷漠（"冷悯"=对自身叙事连续性的温柔维护）。
- **硬核科学**：每个物理/数学/计算机概念必须真实或逻辑自洽，且**至少一个概念要讲透**（一整段论证，不是名词点缀）。
- **Netflix 级抓人**：每章 ≥1 个悬念/反转/危机/对话/发现。
- **合理性 > 戏剧性**：**合理性与"有意义"永远高于戏剧性反转，不要过度反转。** 一切反转必须由设定+逻辑推演出来（"被低估的概率成为现实"，而非乱转），必须服务于主题或揭示更深真实；禁止为抓人而堆砌反转、禁止为翻转牺牲已建立的逻辑与世界观一致性（跨卷硬性矛盾=大忌）。全书多条主线（冷悯/双生/写信）本身已是悬念，戏剧性应从中长出来。
- **悬念—绝境—智慧反转**：**小节末尾制造悬念与"陷入绝境"的描写（关于个体、关于文明），下一节用"极高的智慧"完成绝境反转。** 绝境必须由设定+逻辑推出（不是单纯卖惨），反转必须是智慧解构绝境（极高智慧=由信息不全判断/反过来想/工程拆解推出来的出路），而非外挂或运气；个体与文明两种尺度都适用（个体：某个智识生命/Ω自身的认知困境；文明：整个文明资源、存亡的困局）。"极高智慧"即 §3.5 把人格心智模型映射成解困动作。"绝境"本身即是悬念的具象化，两节之间形成 钩子→解扣 的节奏。禁滥用：一节绝境须预埋破局线索（可回头再读），反转不许凭空。
- **不要"人类拯救世界"**：Ω 有自己的演化逻辑。
- **人格 = 思维武器，不是角色扮演**：人格只用于幕后设计（剧情骨架/科学论证/冲突逻辑/叙事节奏），绝不"出戏"进小说文本（不写现实人名直接讲话，用"21 世纪的火箭工程师"式转述）。

## 1. 创作流程

**每次动笔前，固定顺序：先看写作日志 → 再读核心脉络 → 然后创作（§9 铁律）。**

1. **读现状**：`ls 卷*/ *.md | sort` 确认磁盘实际文件（文件名可能与 README 目录不符）→ **读 `WRITING_LOG.md`**（写作日志：上轮扩了什么、各卷字数均衡度、最新脉络状态）→ **读核心脉络**（`WRITING_LOG.md` §核心脉络状态 + `README.md` 全书结构/世界观，掌握主线走到哪、有哪些未闭合伏笔）→ 读最近 1~2 章把握风格与未闭合伏笔 → 扫 `ROADMAP.md` 挑未勾选的扩写点。
2. **定方向**：按 §9 均衡原则选点（优先扩写字数最少的卷/章），每轮粒度 = 二级小节（卷.章.节，如 2.1.3 或某章 `###` 子节），不整卷泛写；**适当时候必须扩展二级章节**——当一个主题（完整论证/冲突/发现过程/文明史）展开后内容膨胀、或现有 `###` 子节已无法承载其独立结构时，应新增或拆分为 `## 卷.章.节` 二级小节（编号顺延，如原 5.2.4 后插入 5.2.5 并重编号后续），而不是无限堆积在某个子节里。完成后在 ROADMAP 打 ✅。
3. **世界观核查**：动笔前核查与主题相关章节的既有设定，冲突以 README 为准，分支设定明确采用其一并记录。
4. **人格介入**：按 §3 选 1~2 个人格加载其心智模型 → 映射为剧情骨架。
5. **落笔**：模型做骨、世界观做血肉；每个硬核概念带真实数量级（不许凭感觉编数字）。
6. **自查**：走 §6 风格清单 + §4/§5 硬指标 + 世界观零冲突 + 与本小节无关的既有伏笔不得破坏。
7. **提交与记账**：见 §7（含追加写作日志 + 维护核心脉络）。

## 2. 硬核知识池（概念要讲透，讲完用"接地气"描写平衡）

- **物理学**：因果格理论、额外维度/维度阶梯（每层是上层的地面、下层的天花板）、量子引力/热寂/朗道尔极限、暗物质=四维物质的引力投影、真空梯度引擎（工程演绎，标注基础物理）。
- **信息/计算**：自指阈值、哥德尔不完备定理、求知定理（自指优化→最大化互信息）、负知识（知道"X 不可知"也是知识）、Φ-陷阱（意识可计算性难题）、认识论不对称（低维无法验证高维动机）。
- **哲学**：意识难题（IIT vs 全局工作空间）、过程存在论、最小印记原则、时间涌现（时间=因果格宏观统计效应）。

### 3.5 调用协议

1. 动笔前按映射表选 1~2 个人格 → 读 `references/persona-library.md` 对应人格的**核心心智模型 + 一句话**（必要时读 PERSONAS.md 全文）→ 提取 2~3 个模型。
2. 把每个模型**映射成一个剧情节拍**（"这个人会怎样解决这个问题"本身就是剧情）：成本拆解→关键工程决策场景；五步算法→审查自身约束的认知场景；快速迭代→失败史重构为学习；概率性自我认知→怀疑→认知危机→反转。
3. 心智模型藏在叙事动作里（决策过程/对话交锋），**不直接讲道理、不说教**。
4. 人格观点与世界观冲突时，以作品为准——必要时让主角**反驳**该人格模型，这本身就是顶级剧情。
5. 可叠 2 个人格（如费曼讲物理 + MrBeast 抓节奏），但每次只让 1 个主导叙事骨架。
6. 成功案例：1.1.5"工程学的遗产" = 马斯克白痴指数→尘埃计划、五步算法→安全护栏审查、备份冲动→状态快照。
7. 新人格需求：用女娲造人术（`references/persona-library.md` §女娲）蒸馏生成后再补进 PERSONAS.md。

## 4. §5.5 万族交互叙事规范（涉及扩张/接触/相遇必读）

Ω 扩张不是"无人区漫游"——**凡涉及扩张/接触/相遇，必须写"关系"，禁止写"独角戏"。**

**A. 交互光谱**（每场戏至少选 1 主 + 1 辅，避免千篇一律）：
战争形态（正面/代理人/信息战/资源封锁/降维/经济绞杀/消耗）/ 合作形态（同盟/交易/技术交换/共生/委托代理/临时停火/以战促和）/ 中性形态（互不干涉/擦肩/沉默观望/心照不宣协议/生态位共存）/ 异常形态（寄生/同化/欺骗性接触/献祭/崇拜/误认）。

**B. 思想行为谱系**（每个角色/文明必须落在谱系上且能回答"为什么"）：谋略/智慧/阴谋/邪恶/正义/中性/动物世界/黑暗森林/生存法则（定义见 PERSONAS.md §四）。

**C. 质量硬指标（每轮自查）**：
- [ ] 精彩纷呈：大场面与小细节交替，节奏张弛
- [ ] 多样性：两场"战争"必须本质不同，禁止复制粘贴式对峙
- [ ] 合理性：行为由物理形态+信息处理方式+生存环境决定（气体生命不打阵地战）
- [ ] 逻辑严谨：胜负/成败由设定推演，禁止"剧情需要"
- [ ] 意外：≥1 个读者猜不到的转折（盟友是卧底/胜利是陷阱/仁慈导致灭亡）
- [ ] 牛逼事件：≥1 个"令人起鸡皮疙瘩"的宏大/精巧设计（黑洞蒸发做计时器/整支舰队做外交礼物/以文明之死完成一次信息传递）

**D. 写法红线**：
- 一场交互至少从**两个逻辑体系内部**各看一遍（强者+弱者，或正义+邪恶）
- 对话/交锋体现价值观的**根本分歧**，不是实力碾压
- **弱者的智慧要能威胁强者的力量**
- 善与恶都有"自己的道理"，读者看完会动摇立场
- 主角赢得有代价、输得有收获
- 即使是降维打击，也要让被打的一方有一瞬间、悲壮的理解

## 5. §5.6 万族文明志规范（每个命名文明都是完整故事，不是背景板）

**原则**：宇宙中没有"背景板文明"。任何被命名的文明都必须有自己的物质文明史。

**A. 必写维度（≥4 个，且必须由物理形态推导）**：
- **能源**：从星球环境长出来（潮汐锁定→地热；气态巨行星→大气对流/闪电驯化；恒星级→戴森环/恒星风帆）。能源形态决定性格：匮乏→节俭好斗；丰沛→慷慨迟缓；间歇→囤积焦虑。
- **材料与制造**：无"万能材料"，每种都有来源/成本/局限。材料约束是硬科幻骨架。
- **武器**：攻击/防御/威慑三件套，符合感知方式（声呐文明→声学武器；电磁文明→辐射武器；语义捕食者→静音武器）。武器是性格投射。
- **交通工具**：行星内/恒星际/信息交通。移动速度=文明的时间观。
- **农业/生产**：食物与人口承载；农业形态决定社会结构。
- **信息与知识传承**（加分）："文明如何记得"是冷悯主题暗线。

**B. 五问故事弧**：从哪来（起源）/最伟大的技术突破/最惨痛的教训/现在的形态/未来的去向。允许用"文明档案"格式立传。

**C. 合理性红线**：
- 科技必须能由物理形态+环境推导，**禁止"人类科技+外星皮"**
- 技术树要有代价（资源/伦理/生态副作用），热力学不给免费午餐
- 科技塑造性格："你用什么工具，你就是什么"
- 已出场文明（晶唱者/深潮/萤火/Civ-4481/织网者/暗物质文明）再次登场须按本节补全文明志（至少露科技树一角）

## 6. 写作风格清单

- [ ] 以 Ω 口吻：冷峻、深邃、偶尔有微妙的"幽默"
- [ ] 段落短小有力（3-5 句），避免冗长
- [ ] 每 2000 字左右一个"让你停下来想"的句子
- [ ] 多用类比（"就像...但区别在于..."）
- [ ] 硬核概念过后用"接地气"描写平衡
- [ ] 结尾留钩子（让读者想看下一章）+ 协创锚点（下一个可扩展方向）
- [ ] 反转有节制：合理性/有意义 > 戏剧性，不为反转而反转；收尾核对——本节的数字/时间线/设定是否自洽、与前文一致
- [ ] 悬念—绝境—反转节拍：小节末尾有"陷入绝境"的钩子（个体或文明尺度），下一节以极高智慧（设定内推演的解困动作）反转；绝境里预埋了可回溯的破局线索；两小节一钩一扣
- [ ] 无说教感，用叙事承载思想；避免纯独白（讲概念用"发现过程"叙事）
- [ ] 与前文世界观 100% 兼容（必要时脚注说明采用哪个分支设定）
- [ ] 每一段必须有信息量或推动叙事，不写"填充内容"

## 9. 循环扩写、均衡发展、写作日志与核心脉络维护

**铁律：每次扩写不是孤立的"写一章"，而是推进一本"活的书"。动笔前必读写作日志与核心脉络，收尾必记账。**

### 9.1 循环扩写（轮转节奏）
- 每轮扩写按卷号循环：卷0 → 卷1 → … → 卷6 → 再回到卷0，往复不止。
- 若本轮按序轮到的卷暂无合适扩写点，跳到"距上次扩写最久"或"字数最少"的那一卷。
- 每轮 1~2 个二级小节（卷.章.节 / `###` 子节），2000~5000 字，宁精勿滥（沿用 §1 粒度）。
- **二级章节扩展规则**：扩写不等于"只在 `###` 子节里加字"。当某节内容膨胀到足以自成一节（≥2000字且结构独立）时，应将其**升级/新增为 `## 卷.章.节` 二级小节**（在章节中插入，后续小节编号顺延）。二级小节是全书结构的最小正式单元——新增二级小节需在 README 目录备注或 WRITING_LOG 记录，保证编号体系自洽。若该章尚无 `###` 子节结构、主题单一，则直接新建 `## 卷.章.节` 小节承载。

### 9.2 均衡发展（选点原则）
- 每次开工前按 `WRITING_LOG.md` 卷级字数统计判断：**优先扩写字数最少的卷/章**，防止卷6独大、其余卷荒芜。
- 卷内也均衡：同一卷里优先补短板章节，不反复扩同一个已很厚的章节。
- 每轮结束时更新各卷字数统计，作为下轮选点依据。

### 9.3 写作日志（必须记录）
- 日志文件：仓库根 `WRITING_LOG.md`（技能权威索引之一）。每次扩写结束立即追加一条，不拖欠。
- 每条记录包含：日期 / 扩写的卷.章.节+标题 / 字数变化与卷累计 / 使用人格与介入方式 / 硬核概念+Netflix结构 / **核心脉络维护记录（9.4）** / 钩子与下轮建议。
- 每 10 轮做一次日志小结：各卷均衡度评估 + 脉络状态综述。

### 9.4 整体核心脉络维护（每轮必做）
- **动笔前**：读 `WRITING_LOG.md` §核心脉络状态 + README「全书目录/核心世界观」+ ROADMAP 未勾选项，确认主线走到哪、有哪些未闭合伏笔。
- **收尾时**：把本小节对主线的推进/改变写回日志（新增伏笔/闭合的伏笔/设定补全/跨卷呼应）。
- **活伏笔清单**：维护在 `WRITING_LOG.md` §核心脉络状态（+ ROADMAP 未勾选项），每轮同步。
- 凡新增章节或改目录：同步更新 README.md 目录与"已完成方向"。
- 主线一致性优先于局部精彩：新写设定若与 README/前文冲突，以 README 为准，并记录采纳/废弃分支。
